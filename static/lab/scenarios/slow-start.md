# Slow to start, and slow after

> Takes ages to start and the fan roars. They don't need the game launcher or the chat app at start-up. Keep the antivirus.

---

## Task Manager

- **Processes**: sort by **CPU** to find what's using it all. **End task** stops it (or `taskkill /im name.exe`).
- **Startup apps**: what starts with Windows, and its **impact**. **Disable** what isn't needed.
- Never turn off the **antivirus** to speed things up.

```quiz
Where do you stop an app from starting with Windows?
- [x] Task Manager › Startup apps
- [ ] Device Manager
- [ ] Disk Management
```

```quiz
Which start-up app should stay on?
- [x] Antivirus
- [ ] Game launcher
- [ ] Chat app
```
