# Build an office PC

> The office needs a PC for email and spreadsheets: nothing fancy, and no money for a graphics card.

Everything has to **fit together**. Before you put a part in, read its spec card on the bench.

---

## What has to match

- **CPU and motherboard**: the same **socket** (AM4, AM5, LGA1700). A CPU for another socket won't go in.
- **Memory and motherboard**: the same **DDR generation**. DDR4 and DDR5 have their notch in different places.
- **No graphics card?** Then the CPU needs **its own graphics**. AMD marks those with a **G** (5600G); Intel's **F** models have none (12700KF).
- **Motherboard and case**: the case has to take the board's **form factor** (ATX, Micro-ATX, Mini-ITX).

```quiz
This PC has no graphics card. Which CPU can it use?
- [x] One with its own graphics, like an AMD G model
- [ ] Any CPU, as long as the socket matches
- [ ] An Intel F model
```

```quiz
A DDR5 stick won't go into a slot. Why?
- [x] The board takes DDR4: the notch is in a different place
- [ ] The stick is upside down
- [ ] The slot needs a BIOS update first
```

## Build it

Start with the case, then the board, CPU, cooler, memory, power supply and drive. Plug in the 24-pin, the CPU power and the drive's SATA power, and put the monitor into the **motherboard**.
